# 戦闘用の効果音

CC0のレーザー・金属打撃・爆発・風切り・通知音を、ゲームのテンポに合わせて
切り出し、帯域調整、重ね合わせして使用。配布元・作者・用途は `CREDITS.md` を参照。

- shot: 短いレーザー＋機械的な発射の芯。フィーバー連射もこの音を使う。
- charge: 低域を加えた、単発のチャージショット専用音。
- hit: 短い金属への命中。destroy: 爆発の低域＋破片の余韻。
- damage: 自機の硬い衝撃＋短い警告音。敵の撃破音とは区別する。
- dodge: 風切り＋噴射。slash: 風切り＋刃の擦過。slash_finish: 低い衝撃を伴う決め技。
- fever / skill_ready / clear / fail: 起動・準備完了・クリア・失敗の通知。

12用途・20ファイル。shot / hit / destroy / slash は3テイクから同じものが連続しないよう選ぶ。
音程・強さの微変化は戦闘音だけ。BGMと通知音の音程は固定。
同時発音枠は効果音25＋BGM3のまま。PCMとボイスは入場時に確保し、プレイ中には生成しない。
大量撃破時は発音間隔を制限し、残像連撃中の爆発だけ音量を下げて決め技を埋もれさせない。

48kHz・16bit・ステレオPCM。ピークを0.50～0.70に制限し、両端のフェードでクリックを防ぐ。
数値検査は歪み・無音・容量の確認用であり、音色の好みは実際のゲームで確認する。

再編集にはPythonのnumpy / scipy / soundfileが必要。ゲームの実行には不要。
`python project/tools/GenerateCombatSounds.py <素材フォルダ>`
原素材は開発用 `assets_source/audio_combat_20260927` に保存し、実行配布には加工済み素材だけを含める。
